# KILN HQ — Agent Training Center

One room for the fleet and the library.

- **Command** — live count, heat, yard log, who holds what
- **Agents** — roster, briefs, kits
- **Skills** — standing instructions, versions, coverage
- **Training** — send an agent into the kiln, pass or return
- **The Yard** — floors and domains

State lives in the browser (`localStorage`). Seed data ships with the house.

```
npm install
npm run dev
```
